## Proyectos destacados

### [PlannerOn](https://github.com/ErikSneyPlata/PlannerOn) · Productividad personal

Aplicación full stack para organizar tareas, proyectos, agenda, hábitos, notas, sesiones de enfoque y finanzas personales.

- **Problema:** la planificación personal puede quedar repartida entre herramientas distintas.
- **Solución:** un espacio único con módulos conectados y panel de estadísticas.
- **Decisión técnica:** React y TypeScript consumen una API REST en Express; Prisma y PostgreSQL gestionan los datos.
- **Stack:** React · TypeScript · Node.js · Express · Prisma · PostgreSQL  
  [Ver demo](https://planneron.vercel.app)

### [XTREMEGYM](https://github.com/ErikSneyPlata/XTREMEGYM) · Gestión de gimnasios

Sistema para centralizar clientes, membresías, asistencia, inventario, ventas y reportes.

- **Problema:** coordinar la operación diaria del gimnasio desde procesos separados.
- **Solución:** panel administrativo con módulos para los flujos principales del negocio.
- **Decisión técnica:** frontend React conectado a una API Express y PostgreSQL en Supabase.
- **Stack:** React · Node.js · Express · Supabase · PostgreSQL · JWT  
  [Ver demo](https://xtremegymbga.vercel.app)

### [CampusClass](https://github.com/ErikSneyPlata/CampusClass) · Seguimiento académico

Aplicación en Python para organizar información de estudiantes con persistencia basada en archivos JSON.
